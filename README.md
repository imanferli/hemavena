# Hemavena Serang Landing Page

Standalone responsive landing page — tanpa Lovable/React.

## Struktur
- `index.html` — halaman utama
- `styles.css` — desain responsive
- `script.js` — tahun footer
- `assets/` — gambar yang di-upload di percakapan

## Deploy ke Vercel
1. Upload folder ini ke GitHub, atau drag ZIP ke Vercel Drop.
2. Jika memakai GitHub, import repository di Vercel.
3. Framework preset: Other / Static Site.
4. Build command: kosong.
5. Output directory: `.`

Landing page menggunakan link WhatsApp dan Google Maps yang sudah ditentukan.
